Editing features

Tabs, split views, and Explorer

Arrange tabs in multiple rows, sort them by name, extension, or path, and edit in side-by-side or stacked panes. Toggle Explorer from the far-left toolbar button.

Search across a workspace

Find text or regular expressions across a folder, jump to matches, and apply replacements in the active file. Filter matching lines into a new tab.

Bookmarks for search results

Bookmark matching lines, then copy, cut, or delete the marked lines together. Clear search bookmarks while keeping the ones you placed manually.

Column and multi-caret editing

Select rectangular blocks, edit with multiple carets, or switch to overstrike. Set a column ruler and tab width, and convert tabs and spaces.

Advanced line sorting

Sort all or selected lines by up to four character ranges or tab-delimited fields. Use numeric ordering, ignore case, and remove rows whose keys all match.

Code and text navigation

Use syntax highlighting, code folding, bracket matching, and Go to Symbol. Toggle line numbers and word wrap from the toolbar, count words and lines, or insert another text file at the caret.

Macros and shortcuts

Record, name, replay, and repeat edits. Find commands in the Command Palette and customize keyboard shortcuts.

Compare files and inspect bytes

Review a two-file text diff or inspect files in the paged hex view, jump to a byte offset, and overwrite bytes. Standard text editing supports UTF-8 files up to 16 MiB.

Themes and session restore

Cycle through Dark, Light, and High Contrast with one icon. Pick an accent color, restore your workspace session, and register Windows file associations.
