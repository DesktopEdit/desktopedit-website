Editing features

Tabbed editing

Open multiple documents and arrange two editor views side by side.

Find and replace

Search open documents or entire folders with plain text or regular expressions.

Syntax highlighting

Read code with language-specific coloring, folding, and function navigation.

Column editing

Select rectangular blocks or place multiple cursors to edit several lines at once.

Line numbers

Show or hide the line-number column with one toolbar button.

Light and dark themes

Switch the editor and application colors with the half-circle button next to Minimize.
