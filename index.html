Tools for large files

Open gigabyte-scale files

Start reading while DesktopEdit builds its line index in the background. Jump to a line or byte offset as the file opens.

Find, filter and replace

Search with plain text or regular expressions. Filter to matching lines, keep surrounding context or export the results.

Follow live logs

Watch new entries arrive, jump to a timestamp and set an alert for patterns such as ERROR or FATAL.

Work with structured data

Read CSV and TSV as tables, inspect JSON structure and open files inside ZIP and TAR archives.

Edit and save safely

Use undo, column selection and multiple cursors. Saves replace the original file after the new version is written.

Compare and inspect

Compare large files side by side or switch to hex view to see the raw bytes.

Keep your muscle memory

DesktopEdit takes its shortcut cues from UltraEdit. Change the bindings in Help → Keyboard shortcuts.
