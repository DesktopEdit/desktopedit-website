Editing features

Search and replace across files

Search folders, open tabs, or selected text using plain text or regular expressions. Preview replacement diffs and approve which files to update.

Workspace and draft recovery

Reopen DesktopEdit to resume your tabs, untitled notes, unsaved edits, and caret positions. Recovery checkpoints help restore recent work after a crash.

Tabs, split views, and Explorer

Browse project files in Explorer, sort tabs by name, extension, or path, and edit in side-by-side or stacked panes.

JSON and XML tools

Inspect and edit JSON in a tree, jump to values with JSON Pointer, and format or minify the document. Inspect XML elements, evaluate XPath queries, and format XML.

CSV and fixed-width data

Preview and edit delimited data in a table. Sort records, change field separators, or convert between delimited and fixed-width text.

Column and multi-caret editing

Edit rectangular selections or type at multiple carets. Paste as a column, insert numbered sequences, and set column rulers.

Compare files and inspect bytes

Review text diffs in unified or side-by-side views, compare files byte for byte, or find and replace byte sequences in the hex view.

Text encodings

Open and save Unicode and legacy encodings, including Windows-1252, ISO-8859-1, DOS (IBM 437), and EBCDIC (IBM 037).

Macros and smart templates

Record, replay, import, and export editing macros. Reuse snippets with prompted fields and values drawn from the current file, date, or selection.

Advanced line sorting

Sort selected lines or the whole document by up to four character ranges or tab-delimited fields. Use numeric ordering, ignore case, and remove rows whose keys match.

Code and text navigation

Use syntax highlighting, folding, bracket matching, and Go to Symbol. Bookmark matching lines and jump to bookmarks across open tabs.

Change tracking and live logs

See which lines have changed, jump between unsaved changes, and revert an individual change. Follow a saved log as another program appends to it.

Shortcuts, themes, and file associations

Find commands in the Command Palette and customize keyboard shortcuts. Choose Dark, Light, or High Contrast, and register DesktopEdit for your preferred file extensions.
